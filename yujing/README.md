# 语境 · 场景式语言学习（法语 / 日语）

apps.lijinpu.com（原 thuljp.github.io）上的一个纯静态网页应用，手机上可以"添加到主屏幕"当 App 用。
所有学习记录保存在你自己的浏览器里；AI 功能用你自己的 API Key，按量付费。

---

## 一、它怎么帮你学

零基础最难的是"一切都陌生、什么都记不住"。所以语境先给**全貌**，再**按结构一步步学**，学过的内容在快忘的时候再出现。整条路线分三个阶段（底部"课程"）：

### 阶段 1：发音入门

**发音全景**一屏看到整门语言的发音系统，每个格子按掌握程度变色：

- **日语**：五十音按"辅音行 × 元音列"排成表，加上浊音、拗音、长音/促音/拨音。每个假名标出**来源汉字**（あ←安、カ←加），还有例词、平/片假名对照、易混字对比。
- **法语**：元音按"舌头前后 × 嘴巴开合 × 嘴唇圆不圆"排成图；辅音按清浊成对排列；每个音配汉语近似音、口型要领、拼写方式、例词和最小对立词（vous / vu）。

**入门课**：日语 17 课（平假名 → 浊音拗音 → 拍子 → 片假名），法语 10 课（元音 → 鼻化元音 → 辅音 → 拼读规则），每课 5–8 分钟：看全貌 → 逐个认识 → 练到会 → 进入复习。日语学完前 8 课、法语学完前 5 课，就可以进入核心课程。已经会的可以一键跳过。

### 阶段 2：核心课程 A1（每门 12 课）

覆盖欧洲语言框架 A1 的核心语法和约 150 个高频词。每课一个真实情景、一个"学完你能……"的目标，约 15 分钟：

1. **情景对话**：对话一句句出现并朗读，先听、猜意思，需要时再看中文
2. **词汇**：点卡片听发音、看例句，然后玩**配对小游戏**
3. **发现规律**：先猜一道题，再看完整的语法讲解和例句
4. **练习**：听音选义、选词填空、**拼句子**、**对话接话**、看中文开口说；答错的过几题再考一次
5. **完成**：盖章，词进入复习，课文句子变成"看中文说出来"的复习卡，并推荐对应的场景、写作和听写

法语：问候 → être → 冠词与阴阳性 → avoir 与数字 → 点餐 → -er 动词 → 否定与疑问 → 问路 → 时间 → 形容词 → 近将来时 → 复合过去时。
日语：はじめまして → こそあど・の → 数字と買い物 → あります・います → ます形 → に・で・と → 过去与邀请 → 形容词 → 好き・ほしい → て形 → たい → 拉面店综合与形容词过去时。

**知识体系**（课程 → 知识体系）把全部语法点按类别排好，标出在哪一课学、学没学过；点进去看讲解，还能问 AI 老师。

### 阶段 3：进阶练习（底部"练习"）

素材来自你已经学完的课，学得越多，练习越丰富：

- **听写**：听一句写一句，可以慢速播放；法语有重音字母键盘，忽略大小写，漏了重音符号会单独提醒；日语用假名或汉字输入都可以。没听准的可以一键加入复习。
- **跟读**：听原声跟着说，语音识别打分并标出没读准的词；不支持识别的浏览器可以录音自己对比。
- **写作**：按每课的题目写几句，AI 老师逐句批改、给改好的版本和进一步的示范，错句可以加入复习；也可以先看参考范文。
- **场景对话**：① 语块预热 → ② 沉浸听 → ③ 跟读打分 → ④ AI 角色扮演 → ⑤ 复盘，说错的句子自动变成复习卡。完成场景盖"能力印章"。
- **阅读**：用你会的词写成的小故事（AI 生成），可以打开"只听不看"做纯听力练习。

### 每天都做：复习（FSRS 间隔重复）

学过的假名、发音、单词、课文句子、场景语块、纠错句子，都在你"快要忘"的时候出现，先回忆再看答案。卡片背面有字源、例词、口型要领；每张卡都能写**我的联想**，接入 AI 后也可以让 AI 帮你编一个。

"今天"页面每天给出：下一课 → 复习 → 场景 → 一项轮换的练习。

## 二、在网站上的位置

语境是 `apps.lijinpu.com`（原 `thuljp.github.io`）网站下的一个应用，网址 `https://apps.lijinpu.com/yujing/`，和 Job Desk（`/jobdesk/`）并列，从网站首页进入。

更新方式：在本地 `Github_Apps/thuljp.github.io/yujing/` 里改文件 → 双击 `Github_Apps/本地预览.bat` 看效果 → 双击 `Github_Apps/一键发布.bat` 推送到 GitHub。一两分钟后网站生效。学习记录在浏览器里，更新代码不影响记录。

手机上：用 Safari / Chrome 打开网址 → 分享 / 菜单 → **添加到主屏幕**，就像一个独立 App。

## 三、接入 AI（DeepSeek 等国产模型）

AI 负责：和你角色扮演、复盘纠错、生成新场景、补充词库、写每日阅读、回答语法问题。
不接 AI 也能用（角色扮演会变成"脚本模式"），但接上之后体验差别很大。

### 最省事：共用 Job Desk 的设置

在同一台设备上 Job Desk 已经填过 DeepSeek 密钥的话，打开语境 **设置 → AI**，会看到"使用 Job Desk 的设置"按钮，点一下就好（包括中转地址）。

### 单独设置 DeepSeek

DeepSeek 不允许网页直接调用（浏览器跨域限制），需要一个中转。Job Desk 已经用过同样的方式：

1. 如果你已经为 Job Desk 部署过 Cloudflare Worker，语境直接填那个 Worker 的地址就能用 DeepSeek。
2. 想同时支持通义千问、Kimi 等其他服务商：把那个 Worker 的代码换成本项目 `proxy/worker.js`（完全兼容 Job Desk），Deploy 即可。
3. 还没有 Worker：<https://dash.cloudflare.com> → Workers & Pages → Create → Create Worker → Deploy → Edit code，粘贴 `proxy/worker.js` → Deploy，复制地址。
4. 语境 **设置 → AI**：服务商选 DeepSeek，填 API Key 和中转地址，点 **测试连接**。

> 在中国大陆，`workers.dev` 域名有时访问不稳定，可以给 Worker 绑定自己的域名（Settings → Domains & Routes）。

### 其他服务商

设置里预置了 通义千问、Kimi、智谱 GLM、硅基流动和"自定义"。填好 Key 和模型名后点 **测试连接**；提示跨域限制的话，填上中转地址即可。

### 费用与安全

- 一次完整的场景（角色扮演 + 复盘）大约几千个 token，按 DeepSeek 当前价格，每天正常使用一个月通常只要几块钱。以服务商账单为准。
- Key 只保存在你这台设备的浏览器里，不会写进仓库，也不会出现在"导出备份"里。不要把 Key 写进任何上传到 GitHub 的文件。
- 建议在服务商后台给 Key 设置消费上限。

## 四、每日提醒

在 **设置 → 每日提醒** 里：

1. **下载日历提醒（.ics）**——推荐。用 iPhone / 安卓 / 电脑的日历打开，会添加一个每天重复的日程，到点弹提醒，点日程里的链接直接打开语境。
2. **开启网页通知**——当网页或已添加到主屏幕的 App 开着时，到点且当天还没学习会弹通知。（纯静态网页无法在完全关闭时推送，所以日历方式更可靠。）

## 五、发音和语音识别

- 朗读用的是设备自带的语音。iPhone 可以在 **设置 → 辅助功能 → 朗读内容 → 声音** 里下载更自然的法语 / 日语声音（选"增强"或"高级"版本），然后在语境设置里选择。
- 跟读打分和语音输入用的是浏览器的语音识别，**电脑版 Chrome / Edge 效果最好**；Safari 和部分安卓浏览器不支持时，会自动改成"录音 + 回放对比"。

## 六、学习数据：私有仓库同步

网站代码是公开的，但**学习数据只保存在你的浏览器和你的私有仓库 `thuljp/yujing-data` 里**，代码仓库里没有任何学习记录。

### 设置（每台设备一次）

1. GitHub → New repository，名字 `yujing-data`，选 **Private**，勾选 Add a README，创建。
2. 生成令牌：头像 → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
   - Repository access：Only select repositories → 勾 `yujing-data`
   - Permissions → Repository permissions → Contents：**Read and write**
   - 也可以编辑 Job Desk 用的那个令牌，把 `yujing-data` 加进 Repository access，两个应用共用一个令牌（语境设置里有"填入 Job Desk 的令牌"按钮）。
3. 打开 https://apps.lijinpu.com/yujing/ ，会先看到连接页：粘贴令牌（或点"填入 Job Desk 的令牌"）→ **连接**。
4. 手机等其他设备一样：打开网址，填同一个令牌即可，进度会自动取回来。

和 Job Desk 一样，语境是**私人应用**：网页代码公开，但没有连接你私有仓库的设备只能看到连接页，用不了任何功能。想让某台设备退出，到 设置 → 私有仓库同步 → **断开这台设备**。

### 同步规则

- 打开应用时取回最新进度；学习时改动 20 秒后自动保存；切到后台、关闭页面前也会保存。顶栏的小圆点：绿色已同步，黄色同步中，红色出错（点它去设置看原因）。
- 两台设备同一天都学了：每张卡片取最近一次复习的结果，每日统计按设备分别记录再相加，AI 生成的场景、阅读、能力印章取并集，不会互相覆盖。
- 学习计划（每日新词数、提醒时间等）以最后修改的那台设备为准；API Key、朗读声音和语速只保存在各自设备上。
- 声音日记的录音只保存在录制它的设备上，不上传。
- 令牌过期后同步会停下并提示，到 GitHub 重新生成一个，填进设置即可。

### 备份

私有仓库本身就是备份，每次同步都是一次提交，可以在 GitHub 上看到历史版本。设置 → 数据里的"导出备份"仍然可用。

## 七、文件结构

```
index.html              入口
css/style.css           样式（亮色 / 暗色）
js/app.js               路由、"今天"页面、首次设置
js/store.js             数据存储、复习队列、统计
js/fsrs.js              FSRS 间隔重复算法
js/ai.js                大模型接入与所有提示词
js/speech.js            朗读、语音识别、录音、声音日记
js/reminder.js          每日提醒（日历文件 + 网页通知）
js/sync.js              多设备同步（私有仓库 yujing-data）
js/views/*.js           复习、场景、发音全景与入门课（learn）、核心课程与知识体系（course）、练习（practice）、词库、进度、设置页面
js/data/found.js        发音全景与入门课内容（假名字源、例词、法语音素、拼读规则、课程顺序）
js/data/course_fr.js    法语核心课程 12 课（对话、新词、语法、练习题、写作题）
js/data/course_ja.js    日语核心课程 12 课
js/data/fr.js           法语内容（可以直接编辑扩充）
js/data/ja.js           日语内容（可以直接编辑扩充）
proxy/worker.js         全站共用的 AI 中转代码（部署到 Cloudflare；兼容 Job Desk）
sw.js, manifest.webmanifest, icon*  添加到主屏幕 / 离线使用
```

想改内容：直接编辑 `js/data/` 下的文件，格式在各文件开头有说明。
想改 AI 的行为：所有提示词都在 `js/ai.js` 里。
